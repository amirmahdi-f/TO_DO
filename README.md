# TO_DO
in this repo i made a TO_DO list with custom tkinter and i hope you enjoy it# 📝 TO_DO

A simple and modern **To-Do List desktop application** built with **Python** and **CustomTkinter**.

This project was created to provide a clean and easy-to-use interface for managing daily tasks.

## ✨ Features

* ➕ Add new tasks
* 📋 Display and manage tasks
* ✅ Mark tasks as completed
* 🗑️ Remove tasks
* 🖥️ Modern desktop GUI
* 🎨 Built with CustomTkinter
* 🐍 Written entirely in Python
* 🚀 Simple and lightweight

## 🛠️ Technologies

* **Python**
* **CustomTkinter**
* **Tkinter**

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/amirmahdi-f/TO_DO.git
```

### 2. Enter the project directory

```bash
cd TO_DO
```

### 3. Install the required package

Make sure Python is installed on your system, then install CustomTkinter:

```bash
pip install customtkinter
```

### 4. Run the application

```bash
python main.py
```

## 💻 Usage

After launching the application, you can use the interface to manage your tasks.

1. Add a new task.
2. View your tasks in the application.
3. Mark tasks as completed when you finish them.
4. Remove tasks that are no longer needed.
